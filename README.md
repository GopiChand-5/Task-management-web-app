# TaskFlow — Task Management Web Application

A professional, responsive task management web application built with plain HTML, CSS and JavaScript.

## Project purpose

This project was created as a frontend-focused portfolio project to demonstrate:

- HTML5 semantic structure
- CSS3 responsive design
- JavaScript DOM manipulation
- Event handling
- Form validation
- CRUD operations
- LocalStorage persistence
- Array methods and filtering
- Search and sorting
- Responsive UI design

## Features

- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter by All / Active / Completed
- Sort by newest, oldest, priority or due date
- Set task priority
- Set a due date
- Dashboard statistics
- Clear completed tasks
- Data persists after browser refresh using LocalStorage
- Responsive layout for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API
- LocalStorage API

## How to run

No installation is required.

1. Download or clone the project.
2. Open `index.html` in a browser.

For the best development experience, open the project folder in VS Code and use the Live Server extension.
